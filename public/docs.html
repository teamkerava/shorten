POST /api/shorten

shorten a url.

curl -X POST https://yourdomain.com/api/shorten \
  -H 'content-type: application/json' \
  -d '{"url":"https://example.com","duration":"24h","oneTime":true}'
  • url — required. http(s) only.
  • duration — optional. 15m, 1h, 24h (default), 1w, or custom like 36h.
  • oneTime — optional. true burns the link after the recipient reveals it. GET only shows a confirm page (safe for previews/bots); POST burns and redirects. 
{
  "code": "abc123",
  "shortUrl": "https://yourdomain.com/abc123",
  "expiresAt": "2026-09-13T12:00:00.000Z",
  "oneTime": true
}

POST /api/upload

upload an image, get a link back. max 10mb: png jpeg gif webp.

curl -X POST https://yourdomain.com/api/upload \
  -F image=@cat.png -F duration=24h -F oneTime=true
  • image — required. the file.
  • duration — optional, same values as above, 30 days max.
  • oneTime — optional (true/1). burns the link after the recipient reveals it. GET only shows a confirm page (safe for previews/bots); POST burns and serves.

images are deleted automatically after 30 days at the latest.

{
  "code": "a1b2c3d4.png",
  "shortUrl": "https://yourdomain.com/img/a1b2c3d4.png",
  "originalMimeType": "image/png",
  "expiresAt": "2026-09-13T12:00:00.000Z"
}

GET /:code

301 to target. 404 if unknown (or already burned). 410 if expired. one-time links return a 200 confirm page on GET (with no-store); POST burns then 301 redirects with no-store.

GET /img/:code

serves the image. 404 if missing (or already burned). 410 if expired. one-time images return a 200 confirm page on GET (with no-store); POST burns then serves with no-store.

notes

links expire — default 24h. expired entries return 410 and are deleted on access. write APIs are rate-limited per IP (429 + Retry-After when over). errors look like {"error": "..."} with a matching status code.
